What We Are Building

In development · Claude-powered

Warehouse AI Assistant

Problem: small and mid-size warehouses in Vietnam run on spreadsheets and rigid reports. Managers must export data and build pivots by hand just to answer simple questions such as "which SKUs are close to expiry?" or "why did stock drop this week?".

Solution: a natural-language assistant on top of a warehouse management database. Staff ask questions in Vietnamese or English; Claude turns them into safe, read-only queries and returns summaries, alerts and report drafts.

Why Claude: strong multilingual understanding, reliable structured output for query generation, and long-context summarization of operational reports.

  • Claude API
  • Next.js
  • PostgreSQL
  • Prisma

Status: prototype stage. Claude API credits would fund evaluation on anonymized workflows and the first pilot release.
